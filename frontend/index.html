📚 About the Project

This project was built as part of our Software Engineering (SE) course at JSSSTU Mysuru. Our aim was to create a real-world, usable platform that solves the everyday problem of misplaced items on campus. The portal not only helps students and faculty track and return items but also ensures transparency and accountability.
